### Setup

*Prerequisites are <ins>python, verion 3.11.14</ins>, a Steam account, and basic python knowledge.*

1. Download ***The Loopler Demo*** for free on steam. <br>
   The latest version known to work with this <br>
   script is **DEMO.0.0.3.7-10**. <br>
   <details>
   <summary>🛈 Want to ensure you are playing this version?</summary>

   1. Disable auto-updates. <br>

   2. <ins>If you are on linux</ins>, open terminal <br>
   and execute `steam -console`. <br>
   <ins>If you are on windows</ins>,
   open the **run prompt** <br>
   and execute `steam://open/console`<br>
   This will boot steam with console enabled.
   
   3. Find the console in the CONSOLE tab. In this console, execute the following: <br>
   `download_depot 4154070 4154071 4008753507584706854` <br>
   This will download DEMO.0.0.3.7-10. <br>
   *That command is structured as follows: <br>
   download_depot  appid depotid targetmanifestid* <br>
   This will download DEMO.0.0.3.7-10 directly.

   </details> <br>

2. Download the required packages from the **requirements.txt** file. <br>
   To do this, just run `pip install -r requirements.txt` <br>
   In your python terminal It is recommended to do this in a .venv <br>
   virtual environment. Don't know what that is? Google it.

3. Launch the game, and control it using the script's GUI.
