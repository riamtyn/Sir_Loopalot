### Setup
1. Download ***The Loopler Demo*** for free on steam. <br>
   The latest version known to work with this <br>
   script is **DEMO.0.0.3.7-10**. If you would like to <br>
   ensure you are playing this version, disable auto- <br>
   updates. Then, if you are on linux, open terminal <br>
   and execute `steam -console`. If you are on windows, <br> 
   open the **run prompt** and execute `steam://open/console` <br>
   Or, just go to steam://open/console in your browser. <br>
   This will boot steam with console enabled. Find it <br>
   in the CONSOLE tab. In this console, execute the following: <br>
   `download_depot 4154070 4154071 4008753507584706854` <br>
   This will download DEMO.0.0.3.7-10. <br>
   *That command is structured as follows: <br>
   download_depot  appid depotid targetmanifestid*

2. Download the required packages from the **requirements.txt** file. <br>
   To do this, just run `pip install -r requirements.txt` <br>
   In your python terminal It is reccomended to do this in a .venv <br>
   virtual environment. Don't know what that is? Google it.

3. Launch the game, and control it using the script's GUI.
